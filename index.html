Atelier PDF

Fusionner, réorganiser, pivoter, supprimer et extraire des pages. Vos fichiers restent sur votre ordinateur : rien n'est envoyé sur Internet.

    Astuce : faites glisser une page pour la déplacer. Cliquez sur une miniature pour la sélectionner, double-cliquez (ou ✎) pour y ajouter du texte, un rectangle, une image ou une signature.

    Modifier la page

    Faites glisser un élément pour le déplacer, et le coin en bas à droite pour le redimensionner. Touche Suppr pour l'effacer.

    Accents et € acceptés ; les emojis et symboles rares (✓, ★…) deviendront « ? » dans le PDF.

    Rectangle blanc : pratique pour masquer une zone (pensez à vérifier le résultat : le texte caché reste présent dans le fichier).

    Signez dans le cadre avec la souris
